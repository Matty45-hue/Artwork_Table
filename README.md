# Artwork Table – React Assignment

This project is a React application built as part of an internship assignment.  
It displays artwork data from the Art Institute of Chicago API using a data table with pagination and persistent row selection.

The focus of this project is correct data handling, server-side pagination, and selection persistence without prefetching or storing extra data.

---

## Tech Stack

- React (with Vite)
- TypeScript
- PrimeReact
- Art Institute of Chicago Public API

---

## Features

- Displays artwork data in a table
- Server-side pagination (data is fetched page by page)
- Multiple row selection using checkboxes
- Selection persists when navigating between pages
- Custom row selection using an overlay panel
- No prefetching or storage of other page data

---

## API Used
https://api.artic.edu/api/v1/artworks?page=1


The API is called every time the page changes.
