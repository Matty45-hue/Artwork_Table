# Artwork Table

A React application displaying artwork data from the Art Institute of Chicago API with server-side pagination and persistent row selection using PrimeReact DataTable.

## Features

- Server-side pagination
- Row selection with checkboxes
- Persistent selection across pages
- Custom row selection panel

## Setup

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`

## API

Uses https://api.artic.edu/api/v1/artworks for data.
